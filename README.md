# Sage Days Prime Counting Experiments

This repository contains SageMath experiments related to explicit prime-counting estimates, Chebyshev functions, zeta zeros, and explicit formulae.

The initial goal is to build small computational tools for experimenting with:
- the Chebyshev functions $\psi(x)$ and $\vartheta(x)$,
- truncated explicit formulae,
- Riemann zeta zero data,
- and visualizations related to partial RH verification, zero-density estimates, and zero-free regions.
