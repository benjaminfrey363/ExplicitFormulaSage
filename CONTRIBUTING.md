# Contributing

Thanks for contributing to this Sage Days project!

## Workflow

1. Pull the latest version of the repository.
2. Create a branch for your task.
3. Make your changes.
4. Commit with a descriptive message.
5. Open a pull request or share the branch with the group.

Example:

```bash
git checkout -b add-chebyshev-psi
# make changes
git add .
git commit -m "Add basic chebyshev psi function"
git push origin add-chebyshev-psi
